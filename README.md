# ПДД Прогресс

Приложение для отслеживания подготовки к ПДД. Работает как установленное приложение: без масштабирования, без выделения текста, на весь экран.

## Как выложить (GitHub Pages)
1. Загрузи ВСЕ файлы из этой папки в корень репозитория (index.html, manifest.webmanifest, sw.js и три иконки png).
2. Settings → Pages → Branch: main, папка / (root) → Save.
3. Открой ссылку вида https://ТВОЙ_ЛОГИН.github.io/РЕПОЗИТОРИЙ/

## Как поставить на телефон
- iPhone (Safari): Поделиться → «На экран “Домой”».
- Android (Chrome): меню ⋮ → «Установить приложение».

После установки открывай приложение с иконки: так оно запускается на весь экран и работает без интернета.
